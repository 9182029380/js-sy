# JavaScript Backend Training: Class Notes (Basic to Advanced)

48 classes, one topic per class. Every class note has the same layout:

1. Definition
2. Usage (with backend use cases)
3. Description
4. Examples (2 to 3, runnable)
5. Assignments (4)
6. MCQs (3 to 4) with an answer key at the bottom

## How to use
- Install Node.js (version 22 or later is recommended; all examples were run on Node 22).
- Run any example by copying it into a file and running `node file.js`.
- Trainer tip: the **Answer Key** is at the end of each file. Remove it before sharing the notes with learners if you want them to attempt the MCQs first.
- Suggested pace: one class per session (about 60 to 90 minutes: 30 min concept and examples, 20 min assignments, 10 min MCQs).
